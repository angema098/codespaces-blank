🧠 1. Lógica Básica de JavaScript

1.1 Variables y tipos de datos

JavaScript es un lenguaje débilmente tipado. Existen tres formas de declarar variables:

  • let-> variable reasignable (uso moderno recomendado)
  • const-> constante (no reasignable)
  • var-> forma antigua (evitar en código nuevo)

//Tipos primitivos
let nombre = "Lola";        //String
let edad = 21;              //Number
let activo = true;          //Boolean
let nada = null;            //Null
let indefinido;             //Undefined

//Tipos Compuestos
const notas = [4.5, 3.8, 5.0];   //Array
const estudiante = {             //objeto
nombre: "Ana",
edad: 21
};

1.2 Operadores y condicionales

const a = 10, b = 3;
//Aritméticos
a + b // 13
a % b // 1 (módulo)

// Comparación Estricta (===) vs débil (==)
"5" == 5      // true (convierte tipos)
"5" === 5      // false (estricto: tipos iguales)

//Condicional
if (a > b && b > 0) {
    console.log("a es mayor y b positivo");
} else if (a===b) {
    console.log("Son iguales");
} else {
    console.log("Otro caso");
}

1.3 Bucles y funciones

//ucles clásico
for (let i = 0 i < 5; i++) {
    console.log(i);
} 

//Recorrer un array con ForEach
[10, 20, 30].ForEach(n => console.log(n));

//función clásica
function sumar(x,y) {
    return x + y;
}

Función Flecha (arrow function)
const restar = (x, y) => x - y;

console.log(sumar(2, 3)); // 5
console.log(restar(10, 4)); // 6

🌳 2. Manipulación del DOM

2.1 ¿Qué es el DOM?

El DOM(Document Object Model) es la representación en forma de árbol del HTML. JavaScript puede leer y modifivar ese árbol en tiempo real.

Métodos clave para seleccionar elementos:

  • document.getElementById("id")
  • document.querySelector(".clase") => El primero que coincida
  • document.querySelectorAll(".clase") => todos (NodeList)

2.2 Modificar Contenido y Estilos


const titulo = document.querySelector("#miTitulo");
//Cambiar Texto
titulo.textContent = Nuevo Título
titulo.innerHTML = <em>Con HTML</em>;
Cambiar Estilos
titulo.style.color = #4361ee

//Añadir / Quitar clases
titulo.classListadd("destacado");
titulo.classListremove("destacado");

3. Event Listeners

3.1 ¿Qué es un evento?

Un evento es una acción que ocuerre dentro del navegador: un click, una techa, un envio de formulario, un scroll, etc. los Listeners son funciones que reaccionan a esos eventos.

elemeto.addEventListener(click, () =>{
console.log(¡Hiciste click!);
                        });

3.2 Eventos más usados

Click

Click del usuario sobre un elemento.

Input

Se dispara cada vez que el usuario le escribe.

Change

Cuando el valor de un campo cambia y pierde foco.

Submit

Envio de un formulario.

Keydown/ keyup

Cuando se presiona o suelta una tecla.

Mouseover / Mouseout

Cuando el cursor entra o sale de un elemento.

4. La consola del Navegador

4.1 ¿Por qué usar la consola?

Es el Laboratorio del desarrollador: te permite probar código sin afectar el sitio, inspeccionar variables y detectar errores.

Abre la consola con:

  • F12o Ctrl + Shift + I (Windows/Linux)
  • Cmd + Option + I(Mac)
  • Click Derecho => inspeccionar => pestaña Console

Métodos principales de console

console.log("Mensaje Normal");
console.warn("Advertencia");
console.error("Error Critico");
console.info("Información");  

//Mostrar objetos como tabla
console.table([{nombre: "Wanda", nota: 4.5},
{nombre: "Cosmo", nota: 3.8}]);

//Medir Tiempo
console.time(bucle);
for(let i = 0; i < 1000; i++) {}
console.timeEnd(Bucle);

5. Introducción a Jquery

5.1 ¿Qué es Jquery?

Jquery es una libreria de JavaScript creada con el fin de simplificar la manipulación del DOM (Document Object Model), el manejo de eventos y las peticiones AJAX. Aunque hoy existen alternativas modernas (React o VueJS), entender JQuery sigue siendo útil por su presencia en proyectos.

Su lema: "Write less, do more"(Escribe menos, haz más).
